📖 Overview

Welcome to the Static Site Hosting API documentation. This API allows you to upload, manage, and host static websites with automatic backup to Telegram.

Features

  • ✅ Upload ZIP files or individual HTML/CSS/JS files
  • ✅ Automatic Telegram backup (optional)
  • ✅ MongoDB Atlas for metadata storage
  • ✅ Auto-restore on server restart
  • ✅ Site management (delete, restore, download)
  • ✅ Health monitoring and usage stats

🚀 Getting Started

Quick Start

Follow these steps to upload your first static site:

  1. Prepare your static files (HTML, CSS, JS, images)
  2. Create a ZIP file or prepare base64-encoded files
  3. Send a POST request to /api/upload
  4. Access your site at /view/{slug}
💡 Tip: Your site must include an index.html file as the entry point.

🔐 Authentication

Currently, this API does not require authentication. All endpoints are publicly accessible.

⚠️ Important: Consider implementing authentication for production use to prevent unauthorized access.

POST /api/upload

Upload a static site from ZIP file or individual files.

Request Body

Parameter Type Required Description
siteName string Required Name of your site (will be converted to slug)
files array Required Array of file objects
files[].fileName string Required Name of the file
files[].fileData string Required Base64 encoded file content

Example Request

const fs = require('fs');

// Read and encode file
const fileContent = fs.readFileSync('site.zip');
const base64Content = fileContent.toString('base64');

const response = await fetch('/api/upload', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    siteName: 'My Awesome Site',
    files: [{
      fileName: 'site.zip',
      fileData: base64Content
    }]
  })
});

const result = await response.json();
console.log(result);

⚠️ Error Codes

The API uses standard HTTP status codes to indicate success or failure.

Status Code Meaning Description
200 OK Request succeeded
400 Bad Request Invalid request parameters
404 Not Found Resource not found
409 Conflict Site with this name already exists
500 Internal Server Error Server encountered an error

Error Response Format

{
  "ok": false,
  "error": "Site with this name already exists"
}

💡 Examples

Complete Upload Example (Node.js)

const fs = require('fs');
const path = require('path');

async function uploadSite(siteName, zipFilePath) {
  // Read ZIP file
  const fileContent = fs.readFileSync(zipFilePath);
  const base64Content = fileContent.toString('base64');

  // Upload to API
  const response = await fetch('/api/upload', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      siteName: siteName,
      files: [{
        fileName: path.basename(zipFilePath),
        fileData: base64Content
      }]
    })
  });

  const result = await response.json();
  
  if (result.ok) {
    console.log('✅ Site uploaded successfully!');
    console.log('🔗 URL:', result.url);
    console.log('💾 Backup status:', result.backup);
  } else {
    console.error('❌ Upload failed:', result.error);
  }
  
  return result;
}

// Usage
uploadSite('My Portfolio', './site.zip');

Upload Multiple HTML Files

const fs = require('fs');

// Read multiple files
const indexHtml = fs.readFileSync('index.html').toString('base64');
const styleCss = fs.readFileSync('style.css').toString('base64');
const scriptJs = fs.readFileSync('script.js').toString('base64');

// Upload
const response = await fetch('/api/upload', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    siteName: 'Multi File Site',
    files: [
      { fileName: 'index.html', fileData: indexHtml },
      { fileName: 'style.css', fileData: styleCss },
      { fileName: 'script.js', fileData: scriptJs }
    ]
  })
});

const result = await response.json();
console.log(result);

List and Manage Sites

// Get all sites
async function getAllSites() {
  const response = await fetch('/api/admin/sites');
  const data = await response.json();
  return data.sites;
}

// Delete a site
async function deleteSite(slug) {
  const response = await fetch(`/api/admin/site/${slug}/delete`, {
    method: 'POST'
  });
  return await response.json();
}

// Restore a site
async function restoreSite(slug) {
  const response = await fetch(`/api/admin/site/${slug}/restore`, {
    method: 'POST'
  });
  return await response.json();
}

// Usage
const sites = await getAllSites();
console.log('Total sites:', sites.length);

await deleteSite('my-old-site');
await restoreSite('my-old-site');
📝 Note: Make sure your ZIP file contains an index.html in the root or first-level subdirectory.
